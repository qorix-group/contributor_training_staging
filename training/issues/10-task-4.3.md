title: 4.3 Answer the review on pull request #{{PR_R3}}
labels: stage-4
---
Pull request #{{PR_R3}} has two review comments.

- Decide for each comment whether it is right. **Check it against the repository; do not trust it because a reviewer wrote it.**
- Implement the comment that is right. Reply to the other one with your evidence and leave it unresolved.

Before you merge #{{PR_R3}}, add `Closes #<this issue>` to its description: it is the pull request that does this task.

**Done when** #{{PR_R3}} is merged, closes this issue, and both comments have an answer.
